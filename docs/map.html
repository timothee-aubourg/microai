An agent, live

Below, an agent runs in this tab. It has a model of 108,032 numbers, trained from scratch in chapter 19, and three tools: add, sub and mul. Ask it a sum, then something it does not know.

Try: ask a multiplication, then "hello", then a question about France. Watch which lines the model writes and which the program writes.

The lines marked C and A are the only things the model writes. The model does not do the sum. It writes a request, mul 23 45. A plain program reads that request, runs the tool, and writes the result into the text (R). Then the model continues. That is an agent:

The whole idea

An agent is a model that writes text, inside a loop: a program reads what the model wrote, carries out any request in it, adds the result to the text, and calls the model again. It stops when the model writes an answer instead of a request.

Claude Code, a research assistant and this toy all work this way. They differ in the size of the model, the tools on offer, and how carefully the program handles everything around the loop. The map below names each of those parts.

The whole thing on one page

There are three layers. The agent is ordinary software, and nothing in it is learned. It calls the model, which is one learned function. The model is made by training and runs on a machine. Tap a part to see what it does, when you need it, and where the course covers it.

Three ways through

The chapters are numbered in the order they build on each other, from the first counting model up. You do not have to read them in that order. Each path below is a selection, in an order that makes sense for one goal. Pick one and the end of each chapter offers the next on your path.

Five lines to carry

If you read nothing else

  1. A model only predicts the next token. Everything else an agent does is done by the program around it. Chapter 15
  2. An agent is a loop: the model writes, the program acts, the result goes back into the text. Chapter 11
  3. All the model knows at a step is in its context window, and every token in it is paid for at every step. Chapter 16
  4. Text the agent reads can give it orders. Bound what it can do, because you cannot filter everything it reads. Chapter 17
  5. You know a change helped only if you ran the same tests before and after, and read the traces. Chapter 14

Not here yet
